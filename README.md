# Farmer Code Builder

『農家は Replace() されました / The Farmer Was Replaced』用の非公式・日本語ブロック式コード構築アプリです。日本語のブロックをつないで、ゲーム用のコードを生成します。

## Windows版を使う

**[最新版のダウンロード（GitHub Releases）](https://github.com/Aresto1126/farmer-code-builder/releases/latest)**

Windows 10 / 11 の64ビット版を対象としています。Node.jsや開発環境のインストールは不要です。起動後はインターネット接続なしで利用できます。

| ファイル | 使い方 |
|---|---|
| `FarmerCodeBuilder-…-Windows-x64-Portable.exe` | ダウンロードしてダブルクリック。インストール不要 |
| `FarmerCodeBuilder-…-Windows-x64-Setup.exe` | インストーラー。保存先とショートカットを設定して利用 |
| `SHA256SUMS.txt` | 配布exeのSHA256ハッシュ |

現時点のexeは**未署名**です。Windowsが発行元を確認できない旨を表示する場合があります。ポータブル版も編集データはWindowsユーザーごとのアプリ保存領域に保存します。exeと同じフォルダーへの保存ではありません。

## できること

- 日本語ブロックのドラッグ・接続・並べ替え。
- 農作業、移動、センサー、繰り返し、条件分岐、計算、変数、関数。
- 生成コードの即時表示、コード行からブロックへの移動。
- 解放状況に応じた検査。未確認は警告、未解放はコード出力を停止。
- 自動保存、プロジェクト作成・複製・切り替え、JSON保存・復元。
- コードのコピーと `.py` ファイル出力。
- 収穫、全体巡回、ニンジン、関数の4サンプル。

## 基本操作

1. サンプルから始めるか「新規」で作成します。
2. 左のカテゴリーを選び、ブロックを中央へドラッグします。
3. 「プログラムを開始」の中に順番につなぎます。
4. 「解放設定」を実際のゲームの研究状況に合わせます。
5. 赤いエラーを修正して、コードをコピーするか「.py を出力」を押します。
6. ゲーム内コードウィンドウに貼り付けるか、外部編集の手順に従ってファイルを取り込み、ゲーム側で実行します。

ゲーム内の「外部エディター」案内からコードの保存先を確認できます。File Watcherは既存ファイルの外部変更を検出します。ファイルを新規作成・削除した場合、ゲームの資料ではセーブの再読み込みが必要です。本アプリはゲームのセーブやコードを自動で書き換えたり、ゲームを操作したりしません。

## 保存とバックアップ

- 編集内容はアプリ内へ自動保存。「開く」から以前のプロジェクトへ戻せます。
- 「JSON保存」はブロック配置・設定を含む持ち運び用バックアップです。「開く」→「JSONファイルから読み込む」で戻せます。
- `.py` はゲーム用コードだけで、ブロックの配置は含みません。
- ブラウザー版から移行する場合は、ブラウザー版でJSON保存してexe版へ読み込んでください。保存領域は別です。
- 保存先は通常 `%APPDATA%/Farmer Code Builder` 内です。重要なプロジェクトはJSONでも保存してください。
- 関数の引数は0個または1個です。引数なしは定義の引数欄と呼び出しの値を空にします。
- 開始ブロックは1つ。離れた関数定義はコード冒頭へ生成し、それ以外の離れたブロックは下書きとして扱います。

## 対応範囲

Steam build **26462009** のローカル同梱ヘルプとゲーム生成の `__builtins__.py` を照合しています。**生成コードのゲーム内実行は未検証**です。Pythonとは異なるゲーム独自言語として生成し、Pythonの標準ライブラリーには依存しません。

基本ゲーム・単一ドローンが対象です。複数ドローン、採掘DLC、ゲーム再現シミュレーター、既存Pythonからのブロック変換は未対応です。ゲームの現在の地面・資源・研究状態は自動取得しません。

型検査は保守的で、関数の引数・戻り値の完全な型推論や全実行経路の検証は行いません。値を返さない関数の結果を演算へ使わないようにしてください。静的検査合格はゲーム実行成功の保証ではありません。

## 開発・ビルド

Node.js 24 LTSとWindows x64のビルド環境を使用します。

```powershell
git clone https://github.com/Aresto1126/farmer-code-builder.git
cd farmer-code-builder
npm ci
npm test
npm run desktop
```

配布exeの生成:

```powershell
npm run dist:win
```

`release/` にポータブル版とインストーラー版が生成されます。GitHub ActionsでもテストとWindowsビルドを実行し、成果物を保存します。

ブラウザー版の開発は `npm run dev`、Web部分のみのビルドは `npm run build`。既存の `Start-FarmerCodeBuilder.cmd` はNode.jsを使うブラウザー版の補助ランチャーで、exe版とは別です。

| ファイル | 役割 |
|---|---|
| `src/compiler.js` | 制限付きコード生成・静的検査 |
| `src/catalog.js` | API・解放機能のカタログ |
| `src/blocks.js` | 日本語ブロックと接続型 |
| `src/project.js` | プロジェクト検証・保存 |
| `src/main.js` | 編集画面 |
| `desktop/main.js` | Electronウィンドウ・ローカルプロトコル |
| `desktop/policy.js` | ローカルURLの検証 |
| `electron-builder.yml` | Windows配布設定 |
