## デスクトップ化の設計

- 既存画面をElectron内で動かす方式を採用。利用者によるNode.jsの追加導入は不要だが、配布容量は増える。
- レンダラーはsandbox、contextIsolation、webSecurityを有効化し、Node.jsへの直接アクセスを許可しない。
- ローカルの専用プロトコルで同梱ファイルだけを配信。パス逸脱、別ホスト、外部ナビゲーションを拒否。
- ブラウザー版とexe版は保存領域が異なる。JSON入出力で移行する。
- ポータブル版・インストール版の編集データはWindowsユーザーごとのアプリデータ領域へ保存する。

## レビューでの対応

独立した読み取りレビューを実施。ElectronではWeb画面のbeforeunloadを拒否するとブラウザー相当の確認が自動表示されないため、ネイティブの未保存確認を追加した。READMEをexe版の起動・保存・配布手順へ更新した。

起動待ちの表示イベントだけに依存しないよう、画面読み込み完了でもウィンドウを表示する。調査用のコンソール出力やログは公開ソース・配布物に含めていない。

## 残る制限

- ゲーム本体内での生成コード実行は未検証。
- 関数の引数・戻り値の完全な型推論は未対応。
- 開発用依存のelectron-builder関連にはnpm auditのmoderate指摘が残る。アプリに開発用node_modulesは同梱しない。
- Windows 10/11の全環境、ARM64、署名・SmartScreen評価は網羅していない。

公開物にはソース・汎用サンプル・独自アイコン・必要な第三者ライセンスだけを含め、ユーザーのプロジェクト、自動保存データ、ローカル調査ログは含めない。
